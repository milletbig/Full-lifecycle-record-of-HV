# 混动车全生命周期记录

一个面向插电式混合动力（PHEV）车主的单文件、纯前端记账与能耗分析工具。数据保存在浏览器本地，无后端、无账号、无构建步骤，打开 HTML 即可使用。

- 当前版本：`20261118002`
- 应用主体：[混动车全生命周期记录.html](混动车全生命周期记录.html)
- 版本历史：[CHANGELOG.md](CHANGELOG.md)

## 功能概览

### 记账

- 收入 / 支出双向记账，一级类别 + 二级项目；保养项目支持多选，保存时以顿号合并。
- 默认类别：
  - 支出：加油、充电、保险、保养、维修、违章、停车、过路费、洗车、购车/车贷、年检
  - 收入：顺风车
- 支出类别默认按「充电、加油、过路费、停车、洗车、违章、保养、维修、保险、年检、购车/车贷」排序；可在设置页手动排序或恢复固定顺序。
- 选择支出默认「充电」，选择收入默认「顺风车」；首次进入页面同样按支出 + 充电初始化。
- 加油记录填写升数（L）；充电记录可选填电量（kWh），无法统计电量时可留空。
- 充电电量支持口径标注：「桩端 / 车端」二选一，默认桩端；仅在填写了电量时随记录保存，否则为 `null`。
- 充电记录可选填「起始SOC(%)」「终止SOC(%)」：0-100 整数，非必填，终止 SOC 默认 100；超出范围时提示并修正到边界值；切换为非充电类别时自动清空。
- 记录支持通用备注（最多 100 字）。
- 需要里程的类别可录入 HEV、EV 与总里程；HEV + EV 自动合计为总里程，也可手动修改；新增加油 / 充电 / 保养 / 维修记录时自动带出当前车辆最近一组里程数据。

### 记录列表

- 明细列：排序、日期、收/支、类别、具体项目、金额、总里程、HEV、EV、加油（L）、充电(kWh)、起始SOC(%)、终止SOC(%)、备注、操作。
- 筛选：日期范围、收支类型、一级分类；顶部实时显示当前筛选的支出 / 收入合计。
- 分页：每页 10 条。
- 新增记录默认插入列表顶部，并自动回到第一页。
- 每行左侧「≡」手柄支持拖拽排序，顺序立即写入本地存储，刷新后保持。
- 单条记录支持编辑：可修改日期、收支类型、类别、具体项目、金额、升数 / 电量与口径、SOC、总里程、HEV / EV、备注；保存前校验必填项、金额与 SOC 范围，并二次确认。
- 支持删除单条记录；删除车辆会同时清空该车辆下的全部记录（有二次确认）。
- 历史数据不再自动重排；列表顺序完全以当前记录数组顺序为准。

### 智能管家提醒

按当前车辆计算，展示在首页左侧：

- **保养**：取最近一条带里程的「保养」记录，目标里程 = 上次保养里程 + 保养提醒里程；目标日期 = 上次保养日期 + 保养提醒间隔月数。剩余里程 < 1000 km 或剩余天数 < 30 天时标红。
- **保险**：取最近一条「保险」记录，到期日 = 记录日期 + 1 年；剩余 < 30 天标红。
- **年检**：取最近一条「年检」记录，到期日 = 记录日期 + 1 年；剩余 < 30 天标红。
- 同时显示当前车辆的最高总里程。

### 标签与权限

- 二级标签以对象存储：`{ id, name, active, aliases }`；启动时自动把旧的字符串标签迁移为对象，并回填历史记录的 `subCategoryIds`。
- 点击标签可重命名：校验空值、20 字上限、禁止「、」与同类别重名；执行前展示影响条数并生成快照，可撤销上一次标签操作。
- 标签合并：把源标签的历史记录同步替换为目标标签，并停用源标签；标签停用：仅从新记录下拉中移除，历史展示与统计不变，可随时重新启用。
- 操作日志记录重命名、合并、停用、启用、撤销，最多保留 1000 条；设置页展示最近 20 条。
- 本地角色：
  - 管理员：全部权限。
  - 编辑者：可记账、编辑 / 删除记录与拖拽排序，不可维护标签与类别。
  - 只读：不可记账、编辑、删除或拖拽排序。
  - 角色仅用于本地防误操作，任何能打开页面的人都可以切换，不构成账号级安全隔离。

### 数据管理

- **JSON 备份**：导出 `{ vehicles, categories, records, settings }` 四部分；导入会覆盖当前浏览器数据，仅管理员可执行。
- **CSV 导出**：导出全部车辆记录，含 BOM，可直接用 Excel 打开；列包括车辆名称、日期、收支类型、一级类别、具体项目、金额、总里程、HEV、EV、升数、电量、备注。
- **数据清洗**：加载与导入时统一把金额、升数、电量、HEV、EV、总里程转为有限数值，SOC 转为 0-100 整数或 `null`，并按记录 ID 去重；统计与图表聚合再显式做数值化，避免字符串拼接或重复记录导致金额虚高。

## 图表看板

四行两列标准布局：

| 行 | 左侧 | 右侧 |
|---|---|---|
| 第一行 | 里程总览 | 综合净费用走势 |
| 第二行 | 纯电比例 | 综合能耗曲线 |
| 第三行 | 区间电耗 | 油耗分析 |
| 第四行 | 分类支出占比 | 金额走势（默认「充电」，可切换类别） |

- 选中带二级项目的分类时，额外展示「子项目占比」饼图。
- 里程总览为双 Y 轴：左轴为各周期最高总里程，右轴为 HEV / EV 分项里程。
- 油耗分析为双 Y 轴：综合油耗（左轴）、燃油行驶段油耗与馈电油耗（右轴），并绘制官方 WLTC 5.3 L/100km 参考线（L/km 单位下为 0.053）。
- 统一配色：蓝（费用 / 里程 / 金额）、绿（电耗 / 纯电）、琥珀（油耗）、紫（CS 折算）、灰（参考线），固定 Hex，无渐变。
- 图表数据均按当前车辆统计；切换车辆或时间尺度时同步刷新。

### 时间尺度

筛选器包含 6 个选项，默认「今年」，切换后所有图表同步刷新：

| 选项 | 范围 | 聚合粒度 |
|---|---|---|
| 全部 | 全历史 | 自然月（`YYYY-MM`） |
| 今年 | 当前自然年，1 月 1 日起 | 自然月（`YYYY-MM`） |
| 年 | 全历史 | 自然年（`YYYY年`） |
| 季度 | 全历史 | 自然季度 Q1–Q4（`YYYYQn`） |
| 近一年 | 含当前月的最近 12 个自然月 | 自然月（`YYYY-MM`） |
| 近半年 | 含当前月的最近 6 个自然月 | 自然月（`YYYY-MM`） |

所有边界均使用日历月份运算，不使用 30 天 / 365 天近似；启动时会自检跨年、月初月末、闰年 2 月等边界。

## 统计口径

- **综合净费用** = （自购车起累计支出 − 累计收入）÷ 当前周期累计总里程 × 单位系数。
- **综合能耗（费用口径）** = （自购车起累计加油支出 + 累计充电支出）÷ 当前周期累计总里程 × 单位系数。
- **纯电比例** = 周期 EV 里程增量 ÷（HEV + EV 里程增量）× 100%。
- **综合油耗** = 周期燃油量 ÷ 周期总里程增量 × 100。
- **燃油行驶段油耗** = 周期燃油量 ÷ 周期 HEV 里程增量 × 100。
- **馈电油耗（CS 折算）** = 燃油行驶段油耗 × η。
- **区间电耗** = 周期充电支出 ÷ 周期 EV 里程增量 × 单位系数。
- **分类支出占比** = 时间窗内各支出类别的金额合计及占比。
- **子项目占比** = 时间窗内所选分类按二级项目的金额合计及占比。
- **金额走势** = 所选分类在各周期的金额合计。

> 单位系数：费用/电耗单位为「元/百公里」时乘 100，「元/公里」时乘 1；油耗单位为「L/百公里」时乘 100，「L/公里」时乘 1。时间尺度只决定展示哪些周期，不重置累计口径。

## 快速开始

### 直接打开

双击 `混动车全生命周期记录.html`，使用现代浏览器（Chrome / Edge / Firefox）打开。

### 本地静态服务（推荐）

```bash
python -m http.server 8000
```

访问 `http://127.0.0.1:8000/混动车全生命周期记录.html`。

> 页面通过 CDN 加载 Vue 3、Element Plus 与 ECharts，首次打开需要网络。`file://` 与 `http://` 属于不同来源，localStorage 数据不互通，请固定一种访问方式。

### 首次使用

1. 进入「设置」确认车辆、类别与二级标签，按需调整单位、保养周期与 CS 折算系数。
2. 在「首页」录入首条记录；加油填升数，充电可填电量、口径与 SOC，里程类记录填写 HEV / EV。
3. 在图表区选择时间尺度查看趋势，第四行右侧可切换金额走势的分类。
4. 在「设置 → 数据备份与恢复」导出 JSON 备份，建议定期执行。

## 数据模型

单条记录的主要字段：

```json
{
  "id": "唯一标识",
  "vehicleId": "车辆 ID",
  "date": "YYYY-MM-DD",
  "recordType": "expense | income",
  "categoryId": "类别 ID",
  "categoryName": "类别名称",
  "subCategory": "二级项目（多选时以顿号合并）",
  "subCategoryIds": ["二级项目 ID"],
  "amount": 0,
  "hev": 0,
  "ev": 0,
  "totalMileage": 0,
  "liters": 0,
  "kwh": 0,
  "kwhSource": "pile | vehicle | null",
  "startSoc": 0,
  "endSoc": 100,
  "remark": ""
}
```

- `amount`、`liters`、`kwh`、`hev`、`ev`、`totalMileage` 以数值存储；未填写的电量为 `null`。
- `kwhSource` 仅在充电且电量 > 0 时有值：`pile`（桩端）或 `vehicle`（车端）。
- `startSoc` / `endSoc` 仅在充电记录中有值，范围 0-100，未填写为 `null`。
- `subCategoryIds` 为二级标签的稳定 ID，用于标签重命名 / 合并后的历史同步。

### 浏览器存储键

| 键名 | 内容 |
|---|---|
| `hev_vehicles` | 车辆列表 |
| `hev_categories` | 收支类别与二级标签配置 |
| `hev_records` | 全部记录 |
| `hev_app_settings` | 单位、保养周期、CS 系数、角色、类别排序标记 |
| `hev_op_logs` | 标签操作日志（最多 1000 条） |
| `hev_snapshot_latest` | 最近一次标签改名 / 合并的快照，用于撤销 |

备份 JSON 结构：

```json
{
  "vehicles": [],
  "categories": [],
  "records": [],
  "settings": {}
}
```

- Vue 3（全局构建，CDN）

## 版本命名

版本号格式为 `YYYYMMDD` + 三位当日序号，例如 `20261118002`。当前版本：`20261118002`。页面内不展示版本信息与更新日志，全部版本变更统一记录在 [CHANGELOG.md](CHANGELOG.md)。

## 已知限制

- 数据仅存于当前浏览器，清除站点数据会导致记录丢失，请定期导出 JSON 备份。
- 不支持多设备同步或云端协作。
- 依赖 CDN，离线环境下需自行将三个前端库下载到本地并修改引用。
- 备份 JSON 已被 `.gitignore` 排除，不会进入版本库。
- 页面最大宽度 1300px；小于 992px 时图表自动变为单列，配色与数据不变。
- CSV 仅支持导出，不支持导入；SOC 与电量口径不在 CSV 列中。
- 角色校验覆盖记账、编辑 / 删除、拖拽排序、标签与类别维护、JSON 导入；车辆管理未纳入角色校验。
- 金额不做自动单价换算，充电 / 加油金额以用户录入值为准。
