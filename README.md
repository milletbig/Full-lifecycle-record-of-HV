# 混动车全生命周期记录

一个面向插电式混合动力（PHEV）车主的单文件、纯前端记账与能耗分析工具。所有数据保存在浏览器本地，无后端、无账号、无构建步骤，打开 HTML 即可使用。

## 功能概览

### 记账与提醒

- 收入 / 支出双向记账，支持一级类别与二级项目；保养项目支持多选。
- 二级标签支持点击重命名，自动同步历史记录中的同名标签，可一键撤销；操作留痕到 `hev_op_logs`。
- 支持标签合并与停用：合并会同步替换历史记录并停用源标签；停用后不再出现在新记录下拉，历史展示与统计不变，可随时重新启用。
- 本地角色权限：管理员（全部权限）、编辑者（记账，不可维护标签）、只读（仅查看），用于防误操作，不构成账号级安全隔离。
- 设置页可查看最近 20 条标签操作日志（时间、类型、类别、变更、影响条数、结果）。
- 多车辆管理，记录按车辆隔离展示。
- 加油场景记录升数；充电场景可选记录电量（kWh），家充/公桩/免费桩无法统计时可留空。
- 需要里程的类别可录入 HEV、EV 与总里程；新增加油/充电/保养/维修记录时自动带出最近一组里程数据，减少重复录入。
- 智能管家提醒：保养（里程 + 时间双条件）、保险到期、年检到期。
- 明细表支持日期范围、收支类型、一级分类筛选，可编辑与删除记录。
- 一键导出 CSV 明细，便于在 Excel 中二次分析。

### 图表看板（四行两列）

| 行 | 左侧 | 右侧 |
|---|---|---|
| 第一行 | 里程总览 | 综合净费用走势 |
| 第二行 | 纯电比例 | 综合能耗曲线 |
| 第三行 | 区间电耗 | 油耗分析 |
| 第四行 | 分类支出占比 | 金额走势（默认「充电」，可切换类别） |

- 选中带二级项目的分类时，额外展示「子项目占比」饼图。
- 里程总览为双 Y 轴：左轴累计总里程，右轴 HEV / EV 分项里程。
- 油耗分析为双 Y 轴：综合油耗、燃油行驶段油耗、馈电油耗（CS 折算），并标注官方 WLTC 参考线。
- 统一配色：蓝（费用 / 里程 / 金额）、绿（电耗 / 纯电）、琥珀（油耗）、紫（CS 折算）、灰（参考线），固定 Hex，无渐变。

### 时间尺度

筛选器包含 6 个选项，切换后所有图表同步刷新：

| 选项 | 范围 | 聚合粒度 |
|---|---|---|
| 全部 | 全历史 | 自然月 |
| 今年 | 当前自然年（1 月 1 日起） | 自然月 |
| 年 | 全历史 | 自然年 |
| 季度 | 全历史 | 自然季度 Q1–Q4 |
| 近一年 | 含当前月的最近 12 个自然月 | 自然月 |
| 近半年 | 含当前月的最近 6 个自然月 | 自然月 |

所有边界均使用日历月份运算，不使用 30 天 / 365 天近似。

### 设置

- 能耗 / 费用单位（元/百公里、元/公里）与油耗单位（L/百公里、L/公里）。
- 保养提醒里程与间隔月数。
- CS 折算系数 η（0.30–0.80，默认 0.50），用于由燃油行驶段油耗折算馈电油耗。
- 车辆管理、类别管理（收支类型、里程记录开关、二级项目维护）。
- 数据备份与恢复（JSON）、CSV 导出。
- 版本与更新日志（按自然月分组）。

## 统计口径

- **综合费用 / 综合能耗** = 自购车起累计支出 ÷ 自购车起累计总里程（终身平均）。时间尺度只决定展示哪些周期，不改变累计口径。
- **综合净费用** = 累计支出 − 累计收入，再除以累计总里程。
- **纯电比例** = 周期 EV 里程差分 ÷（HEV + EV 里程差分）× 100%。
- **综合油耗** = 周期燃油量 ÷ 周期总里程差分 × 100。
- **燃油行驶段油耗** = 周期燃油量 ÷ 周期 HEV 里程差分 × 100。
- **馈电油耗（CS 折算）** = 燃油行驶段油耗 × η。
- **区间电耗** = 周期充电金额 ÷ 周期 EV 里程差分 × 100。
- **金额走势** = 所选分类在各周期的金额合计。

## 快速开始

### 直接打开

双击 `混动车全生命周期记录.html`，使用现代浏览器（Chrome / Edge / Firefox）打开。

### 本地静态服务（推荐）

```bash
python -m http.server 8000
```

访问 `http://127.0.0.1:8000/混动车全生命周期记录.html`。

> 页面通过 CDN 加载 Vue 3、Element Plus 与 ECharts，首次打开需要网络。使用 `file://` 与 `http://` 访问时浏览器会视为不同来源，localStorage 数据不互通，请固定一种访问方式。

### 首次使用

1. 进入「设置」确认车辆与类别，按需维护二级项目。
2. 在「首页」录入首条记录；加油记录填写升数，里程类记录填写 HEV / EV 里程。
3. 在图表区选择时间尺度查看趋势，第四行右侧可切换金额走势的分类维度。
4. 在「设置 → 数据备份与恢复」导出 JSON 备份，建议定期执行。

## 数据模型

单条记录的主要字段：

```json
{
  "id": "唯一标识",
  "vehicleId": "车辆 ID",
  "date": "YYYY-MM-DD",
  "recordType": "expense | income",
  "categoryId": "类别 ID",
  "categoryName": "类别名称",
  "subCategory": "二级项目（多选时以顿号合并）",
  "amount": 0,
  "hev": 0,
  "ev": 0,
  "totalMileage": 0,
  "liters": 0,
  "kwh": 0
}
```

浏览器存储键：

| 键名 | 内容 |
|---|---|
| `hev_vehicles` | 车辆列表 |
| `hev_categories` | 收支类别与二级项目配置 |
| `hev_records` | 全部记录 |
| `hev_app_settings` | 单位、保养周期、CS 系数、本地角色等设置 |
| `hev_op_logs` | 标签操作日志（最多 1000 条） |
| `hev_snapshot_latest` | 最近一次标签改名/合并的快照，用于撤销 |

备份文件包含 `vehicles`、`categories`、`records`、`settings` 四部分；恢复时会覆盖当前浏览器数据。

## 技术栈

- Vue 3（全局构建，CDN）
- Element Plus（UI 组件，CDN）
- Apache ECharts（图表，CDN）
- 原生 localStorage 持久化
- 无 npm、无打包、无后端

## 版本命名

版本号格式为 `YYYYMMDD` + 三位当日序号，例如 `20261116001`。当前版本：`20261116001`。版本日志在页面「设置 → 版本与更新日志」中按自然月分组展示。

## 已知限制

- 数据仅存于当前浏览器，清除站点数据会导致记录丢失，请定期导出 JSON 备份。
- 不支持多设备同步或云端协作。
- 依赖 CDN，离线环境下需自行将三个前端库下载到本地并修改引用。
- 备份 JSON 已被 `.gitignore` 排除，不会进入版本库。
- 页面最大宽度 1300px；小于 992px 时图表自动变为单列，配色与数据不变。
